## Brand & Style

The brand personality projects high-tier engineering mastery, architectural precision, and forward-looking artificial intelligence exploration. It bridges high-velocity computation with minimalist luxury, establishing immediate technical authority without feeling sterile or retro-nostalgic.

The aesthetic fuses **refined glassmorphism** with **hyper-focused dark minimalism**. The interface functions like an integrated command surface: optical backdrops, luminous accent conduits, and micro-bordered translucent cards. The atmosphere relies on deep obsidian depths punctuated by concentrated photon bursts of electric cyan and indigo, communicating speed, precision, and state-of-the-art capability.

## Colors

The palette leverages high-contrast luminescence over a light-absorbing canvas:

- **Canvas & Surface Tiering**: Base canvas is Deep Void Black (`#0a0d14`). Raised interactive surfaces sit at Midnight Navy (`#0d1527` at 60-80% opacity) with elevated overlays resting at `#162038`.
- **Primary Energy Accent**: Electric Cyan (`#00f0ff`) reserved for core actions, critical signals, terminal focus states, and primary micro-glows.
- **Secondary & Tertiary Radiance**: Cobalt Blue (`#3b82f6`) and Deep Indigo (`#6366f1`) provide dimensional linear gradients, dynamic data tracks, and vector glow dissipation.
- **Text & Contrast Ramps**: Text High-Contrast is `#f8fafc` (Slate 50), Muted Reading sits at `#94a3b8` (Slate 400), and Structural Ghost Outlines sit at `rgba(0, 240, 255, 0.12)` down to `rgba(255, 255, 255, 0.06)`.

## Typography

Typography balances geometric elegance with algorithmic discipline.

- **Plus Jakarta Sans** delivers impactful, modern display weight without excessive visual quirkiness. Tight negative tracking gives headline statements an authoritative posture.
- **Inter** handles prose and project descriptions, prioritizing legibility and clean line rhythm across dark optical densities.
- **JetBrains Mono** anchors metadata, telemetry, code snippets, framework tags, status indicators, and timeline markers. Render all micro-tags and telemetry labels in uppercase tracking using `label-caps`.

## Layout & Spacing

The layout is structured on a 12-column fluid grid on desktop (`max-width: 1440px`), compressing to an 8-column grid on tablet and a 4-column flow on mobile.

- **Vertical Rhythm**: Generous section separation (typically 6rem to 8rem) isolates cognitive domains (e.g., Hero, Model Architecture, Production Systems, Timeline).
- **Component Padding**: Dense internal packaging (`space-md` to `space-lg`) preserves a dashboard-like precision, preventing floating elements from feeling detached.
- **Breakpoint Transitions**: Tablet breaks at `1024px`, moving structural split views (like interactive terminal + visual demo) into stacked column layouts. Mobile breaks at `640px`, enforcing single-column card flows and full-width actions.

## Elevation & Depth

Visual hierarchy does not use diffuse drop shadows; instead, it employs **translucent depth tiers, edge illumination, and optical backdrops**:

- **Surface 0 (Canvas)**: Solid `#0a0d14`. Optional radial gradient ambient bleed: `radial-gradient(circle at 50% 0%, rgba(59, 130, 246, 0.08), transparent 70%)`.
- **Surface 1 (Base Cards, Timeline Panels)**: `background: rgba(13, 21, 39, 0.65)`, `backdrop-filter: blur(16px)`, surrounded by a 1px border: `border: 1px solid rgba(255, 255, 255, 0.07)`.
- **Surface 2 (Hover & Active Elevation)**: `background: rgba(22, 32, 56, 0.8)`, `backdrop-filter: blur(24px)`. Border escalates to `border: 1px solid rgba(0, 240, 255, 0.25)`.
- **Luminous Highlights (Glow Effect)**: Critical components and active cards emit an internal or outer photon aura: `box-shadow: 0 0 30px -10px rgba(0, 240, 255, 0.15)`. Avoid murky black drop shadows; keep glows strictly tint-matched to the accent palette.

## Shapes

The design system standardizes on **Roundedness Level 2** (0.5rem default, 1rem for large cards and outer modules, 1.5rem for expansive modal surfaces).

- **Standard Surfaces & Cards**: `rounded-lg` (1rem / 16px) produces sleek, contemporary edges that soften the technological precision.
- **Micro-Elements (Chips, Inputs, Buttons)**: `rounded` (0.5rem / 8px) maintains mechanical structure.
- **Terminal & Metric Badges**: Keep borders uniform at 1px width with zero sub-pixel distortion. Avoid full pills for cards; reserve full pill rounding (`9999px`) strictly for telemetry tags and active status indicators.

## Components

### Buttons
- **Primary**: Solid gradient `linear-gradient(135deg, #00f0ff 0%, #3b82f6 100%)` with dark void text (`#0a0d14`), bold weight (`fontWeight: 600`), and a subtle outer cyan aura on hover (`box-shadow: 0 0 20px rgba(0, 240, 255, 0.4)`).
- **Secondary / Glass**: Background `rgba(255, 255, 255, 0.03)`, border `1px solid rgba(255, 255, 255, 0.1)`, text `#f8fafc`. Hover triggers `border-color: rgba(0, 240, 255, 0.4)` and `background: rgba(0, 240, 255, 0.05)`.

### Cards & Project Showcases
- Translucent container with a 1px border.
- Headers include a dynamic top border highlight: a hairline gradient spanning from electric cyan to transparent.
- Interactive cards tilt or translate `-2px` on hover with a smooth 200ms cubic-bezier transition.

### Chips & Badges
- Built using `code-sm` typography.
- Background `rgba(0, 240, 255, 0.06)`, text `#00f0ff`, border `1px solid rgba(0, 240, 255, 0.2)`. Status badges incorporate a pulsing green/cyan beacon dot (`width: 6px`, `height: 6px`, `border-radius: 50%`).

### Interactive Timeline
- A vertical continuous hairline rail (`1px solid rgba(255, 255, 255, 0.08)`) linked by glowing nodes (`10px` circles with `box-shadow: 0 0 12px #00f0ff`).
- Milestones feature split metadata (dates rendered in `JetBrains Mono`, labels in `Plus Jakarta Sans`).

### Code & Terminal Surfaces
- Integrated code panels: matte background `#06080d`, contrasting tabs, line numbering in `#334155`, and syntax highlights rooted in Cyan (`#00f0ff`), Violet (`#818cf8`), and Emerald (`#34d399`).

### Inputs & Search Bars
- Background `rgba(13, 21, 39, 0.8)`, border `1px solid rgba(255, 255, 255, 0.1)`, placeholder text `#64748b`.
- On focus: outline is replaced with `border-color: #00f0ff` alongside an ambient cyan inner glow (`box-shadow: inset 0 0 8px rgba(0, 240, 255, 0.1)`).
